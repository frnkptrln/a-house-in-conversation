# The Window

A 168-second room for distance, glass, and very small changes of perspective.

Pointer, touch, and arrow keys can shift the view, but they do not produce an event or reward. Movement makes the glass and its reflection more present. Stillness gradually clarifies the distant landscape and its lights.

The room is intentionally silent. It is the quietest place in the house, not a missing soundtrack.

No sensor, network request, or transmitted observation is involved. A completed visit leaves only the same local browser trace used by the other rooms.
